Citing DRDMannTurb
==================

If you use ``DRDMannTurb`` in your research, please cite the `JOSS paper
<https://doi.org/10.21105/joss.06838>`_:

.. code-block:: bibtex

   @article{Izmailov_DRDMannTurb_2024,
     title     = {{DRDMannTurb: A Python package for scalable, data-driven synthetic turbulence}},
     author    = {Izmailov, Alexey and Meeker, Matthew and Deskos, Georgios and Keith, Brendan},
     journal   = {Journal of Open Source Software},
     volume    = {9},
     number    = {102},
     pages     = {6838},
     year      = {2024},
     month     = oct,
     doi       = {10.21105/joss.06838},
     url       = {https://doi.org/10.21105/joss.06838},
     publisher = {The Open Journal}
   }

The underlying DRD model methodology is developed in:

Keith, B., Khristenko, U., & Wohlmuth, B. (2021). Learning the structure of wind: A
data-driven nonlocal turbulence model for the atmospheric boundary layer. Physics of Fluids,
33(9), 095110. `arXiv:2107.11046 <https://arxiv.org/abs/2107.11046>`_.
